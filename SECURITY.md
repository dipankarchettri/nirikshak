# Security Policy

Nirikshak is a research tool for detecting eavesdroppers on QKD links. It is not a certified
security product, and its results should not be the only safeguard on a real link.

## Reporting a vulnerability

If you find a flaw that would let an attack go undetected, cause false verdicts, or leak data or
credentials, please report it privately rather than in a public issue:

- use GitHub's **Report a vulnerability** button under this repository's **Security** tab, or
- contact the maintainer, [@dipankarchettri](https://github.com/dipankarchettri), privately.

Please include the steps or data needed to reproduce it. We aim to reply within two weeks.

## Credentials

Never put an IBM Quantum API key in an issue, pull request, notebook output or commit. If you
leaked one, revoke it on the IBM Quantum Platform straight away.
